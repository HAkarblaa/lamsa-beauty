# لمسة بيوتي

واجهة متجر مكياج عربية باتجاه RTL. تعمل بملفات HTML وCSS وJavaScript وتعرض صور المنتجات محلياً.

## المعاينة والرفع

1. فك ضغط الملف وافتح `index.html` للمعاينة.
2. أنشئ مستودعاً على GitHub وارفع محتويات الملف المضغوط إلى جذر المستودع، بحيث يظهر `index.html` بجانب `README.md`.
3. لنشر معاينة ويب من المستودع، يمكن تفعيل GitHub Pages واختيار فرع `main` ومجلد الجذر. جميع المسارات نسبية لتعمل المعاينة داخل مسار المستودع.

## تجربة الشراء

اختاري منتجاً ولونه وكميته، ثم افتحي السلة. رمز الخصم التجريبي `BEAUTY10` يخصم ١٠٪ من قيمة المنتجات. رسوم التوصيل النموذجية ٤٬٠٠٠ د.ع. بعد كتابة بيانات توصيل وهمية، يؤكد الزر الطلب محلياً ويعرض رقمه في «طلباتي».

الدخول وإنشاء الحساب تجربة محلية دون كلمة مرور. السلة والمفضلة والحساب التجريبي وسجل الطلبات مشتركة ضمن المتصفح نفسه. بيانات الاستلام التفصيلية لا تُحفظ في سجل الطلبات. النسخة الحالية تحتاج إلى قاعدة بيانات ومصادقة وخدمة طلبات قبل تشغيل المتجر للزبائن واستقبال طلبات حقيقية.

المنتجات والأسعار والإعلانات قابلة للتعديل في `catalog.js` والألوان والتخطيط في `style.css`. ملفات المشروع تصلح أساساً لتغليف التطبيق في المرحلة التالية.
